# joaoribeiromedeiros.github.io

Personal site of João Ribeiro Medeiros, served by GitHub Pages from the `main` branch.
Live at https://joaoribeiromedeiros.github.io/

Plain HTML and CSS, no build step. To edit, change the `.html` files or `style.css` and push.

| File | Page |
|---|---|
| `index.html` | Home: hero, about, highlights |
| `experience.html` | Career timeline |
| `projects.html` | RAGenesis and open experiments |
| `research.html` | Education, publications, writing |
| `404.html` | Not-found page |
| `style.css` | Shared stylesheet (design tokens at the top) |
| `assets/` | Background art (`bg.webp` / `bg.jpg`) and social preview (`og.jpg`) |

The header, nav and footer are repeated in every page; when you change one, change all of them.
